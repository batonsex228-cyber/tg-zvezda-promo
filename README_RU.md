# Два Telegram-бота в одном GitHub и Docker Compose

**Источник 1:** ДЗЛ «Звёздочка» Telegram v1.0.5 (Cloudflare Bot API, заявки на смены, FAQ и менеджер).
**Источник 2:** «Турист» v0.18.3 CLEAN UI (Telegram-бот + FastAPI Mini App).

Один GitHub-репозиторий `batonsex228-cyber/tg-zvezda-promo` и одна команда
`docker compose up -d`, но **три контейнера**: `zvezdochka`, `tourist`, `caddy`.
Это надёжнее, чем запускать два бота в одном процессе.

## Файлы

- `bots/zvezdochka/` - отдельное приложение и свой Dockerfile.
- `bots/tourist/` - приложение, Mini App, тесты, статика и Dockerfile.
- `compose.yaml` - общий запуск и пять отдельных Docker-томов.
- `.env.example` - один шаблон настроек, два токена под разными именами.
- `.github/workflows/publish-ghcr.yml` - тестирование и публикация двух образов.
- `scripts/migrate_existing_repo.py` - безопасная миграция существующего репозитория.
- `scripts/dual_release_check.py` - офлайн-проверка структуры.
- `DEPLOY_RU.md` - пошаговая инструкция для Codespaces и Миши.

## Что обязательно настроить у Миши

**Два разных Telegram-токена**: `ZVEZDOCHKA_BOT_TOKEN`, `TOURIST_BOT_TOKEN`.
Для «Туриста» дополнительно обязательно указать публичный HTTPS-домен
(`TOURIST_DOMAIN`) и числовой Telegram ID владельца (`TOURIST_OWNER_ID`).
Без домена полноценный Mini App не откроется. Звёздочка может отвечать
на FAQ и без менеджера, но для отправки заявок нужен `ZVEZDOCHKA_MANAGER_ID`.

**Cloudflare Worker** `telegram-api-proxy.aleksejnazarov93583.workers.dev`
направляет только исходящие Telegram Bot API-запросы.
Он **не заменяет HTTPS-домен Mini App**. Передавать ему данные и токены
можно только если вы доверяете владельцу Worker и его настройкам.

## Перед публикацией

После перехода в один репозиторий используйте **только корневой** `compose.yaml`.
Не копируйте `.env`, SQLite, резервные копии или токены в GitHub.
У обоих ботов должны быть свои действительные BotFather-токены; нельзя
одновременно запускать локальную Windows-копию с тем же токеном.

## Отличия от Windows-сборок

Действующий файл Google Apps Script «Звёздочки» не изменён. Автосинхронизация
для двух ботов с Google не включается сама по себе. По умолчанию «Звёздочка»
использует локальные заявки менеджеру, а «Турист» показывает демонстрационное
расписание на новой базе (`TOURIST_SHOWCASE_MODE=true`).

Файл шрифта из исходного проекта «Турист» не включён в пакет;
веб-интерфейс использует штатные системные шрифты. Остальные изображения,
исходный логотип и сценарии Mini App сохранены.

Подробности: `DEPLOY_RU.md`.
