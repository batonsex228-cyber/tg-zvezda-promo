# ДЗЛ «Звёздочка» - Telegram-бот для Windows

Самостоятельная Telegram-версия на основе исходников VK-бота v6.0.5. **VK-бот не изменяется**.

## Запуск (Windows 10/11)
1. Распакуйте ZIP в обычную папку (например `C:\ZvezdochkaTelegram`). Не запускайте BAT внутри ZIP.
2. Создайте Telegram-бота в официальном [@BotFather](https://t.me/BotFather) командой `/newbot`. Скопируйте токен.
3. Дважды щёлкните **`START_TELEGRAM.bat`**. Запуск v1.0.3 использует изолированный Python 3.12 через uv: скачает проверенный uv, установит собственный Python 3.12 и библиотеки без зависимости от PATH или системного Python, предложит скрытый ввод токена и запустит бота.
4. В Telegram откройте созданного бота и нажмите `/start`.
5. Держите окно BAT открытым и компьютер в сети. `Ctrl+C` останавливает бота.

Первый запуск требует интернета. При следующем запуске токен берётся из `.env`, вводить снова не нужно.

## Менеджер и заявки
Для уведомлений и возврата ответов нужен **TELEGRAM_MANAGER_USER_ID**. Пусть менеджер откроет бота, отправит `/start`, затем `/id`. Введите полученный числовой ID в `.env` и перезапустите BAT.

Менеджер: `#admin`, `#open`, `#stats`, `#знания`, `#рассылка`. Кнопки ответов и подтверждений адаптированы для Telegram. Сохраняется защита от повторных нажатий кнопок и заявок. До указания ID менеджера заявления с персональными данными не собираются.

**Дополнительные интеграции** включаются только после настройки: `BOOKINGS_ENABLED=true` для существующего Google Apps Script, `SHIFT_BOOKINGS_ENABLED=true` для заявок на смены (при настроенном ID менеджера достаточно локальной базы, Google-таблица необязательна), `SMART_HANDOFF_ENABLED=true` для анкеты передачи специалисту. Настройки смотрите в `.env.example`.

> Схема Google Apps Script остаётся исходной. В запросах бронирования сохранились технические названия полей `vk_user_id` и `vk_peer_id`, потому что сервер Apps Script принимает именно их. Значения содержат Telegram ID. Для одновременной работы VK и Telegram с *одной* таблицей следует отдельно разнести платформы в Apps Script. Пока используйте **отдельную тестовую таблицу** либо выключите бронирование (`BOOKINGS_ENABLED=false`).

Никаких ключей OpenAI для запуска не требуется. Без `OPENAI_API_KEY` действует локальная база ответов и передача неизвестных вопросов менеджеру. Динамические цены и наличие мест бот не выдумывает.

## Самопроверка
В терминале папки проекта:

```powershell
.venv\Scripts\python.exe scripts\local_self_test.py
```

## Важно
- Не публикуйте `.env`, токен и `runtime`.
- Для Telegram long polling должен работать только один экземпляр с данным токеном; запуск двух копий приведёт к конфликту обновлений.
- Скрипт запуска сбрасывает установленный webhook **без удаления ожидающих сообщений** для перехода на polling.
- Сборка протестирована офлайн, но реальное соединение с Telegram и Google нужно проверить на Вашем ПК.
- По вопросам оплаты, подтверждения мест или срочных ситуаций используются безопасные сценарии, а не придуманные ответы.

## Исправление v1.0.1 (Windows Python после winget)
- Исправлена ошибка `[ERROR] Python 3.11-3.13 is required` после успешной установки `Python.Python.3.12`.
- Скрипт обновляет PATH в текущем процессе, проверяет Python Launcher, реестр установленных Python, типовые расположения `python.exe` и пакеты WinGet.
- **Если у вас уже распакована v1.0.0**, достаточно заменить `scripts/windows_start.ps1` из патча v1.0.1, затем снова запустить тот же `START_TELEGRAM.bat`.
- Если после обновления всё ещё появляется ошибка поиска Python, перезагрузите Windows, откройте CMD и выполните `py -0p` и `where python`. Передавайте только диагностический вывод, не токен.

## Исправление v1.0.2 - системный Python больше не нужен
- Старый BAT находил Python через PATH/реестр и на некоторых Windows ошибочно писал, что Python отсутствует. v1.0.2 НЕ обращается к winget и не зависит от установленного Python.
- Один `START_TELEGRAM.bat` скачивает uv 0.13.8 для Windows x64 с GitHub, проверяет SHA-256 и создаёт `.venv` на базе изолированного Python 3.12. Описание uv: https://docs.astral.sh/uv/concepts/python-versions/.
- Требуется Windows 10/11 x64 и подключение к Интернету при первой установке. Если GitHub заблокирован сетью, выводится понятная ошибка.
- Сохраняются `.env`, токен, папка `runtime`. Если `.venv` неисправна, она переименовывается в `.venv_old_YYYYMMDD_HHMMSS` без удаления.
- **Для обновления с v1.0.1**: распакуйте архив `...v1_0_2_UV_BOOTSTRAP_PATCH.zip` в ту же папку с заменой файлов. Не удаляйте `.env` и `runtime`. Дважды нажмите `START_TELEGRAM.bat`.
- Если хотите проверить офлайн-сценарии, после настройки используйте `TEST_LOCAL.bat`.
- Эта сборка проверена автоматическими тестами и содержимое ZIP проверено локально; реальный запуск на пользовательской Windows ещё требуется.


## Обновление v1.0.3 - ответы Reply, приветствия и реакции
- Если сообщение содержит приветствие и вопрос одновременно, бот сначала отправляет нейтральное «Здравствуйте! 👋» отдельным сообщением без цитирования, а затем отвечает **через Telegram Reply** на конкретное входящее сообщение.
- На обычные вопросы бот отвечает через Telegram Reply (выделяется исходное сообщение). Для команд, уведомлений менеджера и ответов на кнопки используется обычное сообщение.
- Короткие фразы «спасибо, хорошо», «Спасибо тебе за помощь», «До свидания», «Хорошо» распознаются как вежливые реплики. Они **не создают обращение к менеджеру**.
- Бот ставит стандартную реакцию ❤️ на благодарности, прощания, короткие подтверждения и emoji-ответы. Если Telegram не разрешает реакцию, ответ текстом всё равно отправляется.
- Вопросы с вежливым началом (например, «Спасибо, а сколько стоит путёвка?») продолжают обычную обработку, не поглощаются обработчиком благодарностей.
- Новая версия не меняет содержимое базы знаний, логику бронирования, Apps Script и настройки, сохранённые в `.env` и `runtime`.
- Обновление с v1.0.2: распакуйте `...v1_0_3_REPLY_HEART_PATCH_FROM_v1_0_2.zip` в рабочую папку с заменой файлов, перезапустите `START_TELEGRAM.bat`. Выключите предыдущий экземпляр, чтобы не возник конфликт Telegram polling.
- Проверки через `TEST_LOCAL.bat` теперь включают отдельный тест реального формата исходящих Reply-сообщений и ❤️-реакций на тестовом (подменённом) API.

**Важно:** показ реакций зависит от правил Telegram для конкретного чата. Логика проверена офлайн, реальное отображение у пользователя проверяется после установки.


## Обновление v1.0.4 - понимание разговорных вопросов и база знаний

**Рекомендуется маленький PATCH поверх v1.0.3.** Не удаляйте `.env`, `.venv` и `runtime`.

- Добавлен каталог `data/semantic_topics.json` с **50 смысловыми темами**. Содержимое подготовлено из аналитического исследования и сверки с официальными страницами лагеря на 17.11.2026.
- Для вопросов своими словами работает локальный слой поиска по понятиям, русским словоформам, сокращениям и умеренным опечаткам. Он не сопоставляет сообщение со 150 точными готовыми фразами.
- Поддерживаются 2-3 связанных вопроса в одном сообщении и краткие уточнения по предыдущей теме (контекст хранится в локальной БД с ограниченным TTL).
- Невозможно гарантировать понимание любой фразы: **без `OPENAI_API_KEY` это проверяемая эвристическая семантика, а не нейросетевая языковая модель**. Тонкости, которых нет в подтверждённых источниках, надо уточнять у менеджера.
- Реальные свободные места, медицинские вопросы, возврат денег, индивидуальные данные о детях не угадываются. Спорные возрастные рамки и продукты с цитрусовыми специально помечены для согласования.
- Базовые кнопки меню получили резервные проверенные сведения на случай недоступного обновления сайта. Цены из локального каталога ограничены сроком актуальности; по его истечении требуется новая проверка.
- Telegram Reply, ❤️-реакции, заявки, Google Apps Script, VK-проект и Windows `uv`-запуск сохранены. Apps Script не менялся.
- Исследовательские формулировки хранятся **в тестах**, а не в словаре точных ответов: `tests/semantic_150_messages.jsonl`, `tests/context_20_dialogues.json`.

Проверка после установки: запустите `TEST_LOCAL.bat`. Он прогоняет старые Telegram-тесты, 150 примеров, 20 диалогов и адаптерный smoke-test на подменённом Telegram API. Проверка на Вашем реальном токене и Windows по-прежнему требуется отдельно.

### Установка PATCH

1. Остановите работающий экземпляр Telegram-бота (`Ctrl+C`).
2. Распакуйте `ZVEZDOCHKA_TELEGRAM_WINDOWS_v1_0_4_SEMANTIC_KB_PATCH_FROM_v1_0_3.zip` прямо в старую папку с заменой файлов.
3. Убедитесь, что рядом с BAT лежит обновлённая папка `data/semantic_topics.json` и `app/semantic_knowledge.py`.
4. Нажмите `TEST_LOCAL.bat`. После успешной проверки запустите `START_TELEGRAM.bat`.
5. Данные и бот-токен в `.env` сохраняются.
