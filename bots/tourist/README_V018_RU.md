# ТУРИСТ — GOLD LOUNGE · v0.18.0 (Visual Polish)

Полная Windows ONE CLICK-сборка Telegram-бота и Mini App. Версия посвящена финальной полировке фирменного интерфейса и доступности; серверная логика, 150 FAQ, заявки, бильярд, админ-панель и уведомления сохранены.

## Что улучшено

- Плавные переходы между разделами, мягкие реакции на нажатие карточек и кнопок, анимации диалоговых окон и уведомлений. Все эффекты локальные, без внешних JS-библиотек и сервисов.
- Единая система типографики (Bahnschrift / Arial Narrow / Segoe UI и системные замены). Шрифты не загружаются с внешних сайтов, поэтому приложение может работать при ограничениях сети.
- Полная поддержка `prefers-reduced-motion`: если включено уменьшение движения, анимации отключаются.
- Исправлена клавиатурная доступность поп-апов: фокус переходит на кнопку закрытия; Tab не уводит его за окно, Escape закрывает, фокус возвращается на прежний элемент.
- Выбранные дни и интервалы времени отмечаются не только цветом, но и `aria-pressed` для вспомогательных технологий.
- Улучшены состояния навигации, подсветка кнопок и читаемость на маленьких экранах; нет склеенных изображений вместо кнопок.
- В BAT обновлена устаревшая надпись с номером версии; CSS/JS снабжены свежими параметрами версии во избежание старого кэша Telegram.
- Оригинальный файл логотипа **не изменялся**; для круглого изображения используется исключительно CSS-маска.

Почему без Vue.js: перенос существующей работающей логики на новый UI-фреймворк добавил бы ненужный риск именно перед приёмкой. Все запрошенные анимации реализованы в CSS + JavaScript без новых зависимостей и без ухудшения работы офлайн.

## Первый запуск на Windows 10/11

1. Распакуйте ZIP полностью, например в `C:\TOURIST_GOLD_018`.
2. Откройте папку `TOURIST_ONE_CLICK` и дважды нажмите **`START_TOURIST.bat`**.
3. При первом запуске добавьте токен, полученный у @BotFather, в окне установщика. Токен не нужно отправлять в чат и не следует фотографировать.
4. Дождитесь запуска бота. Для Mini App внутри Telegram требуется работающий HTTPS-туннель или собственный HTTPS-домен.
5. Чтобы открыть админку как владелец: отправьте боту `/id`, запустите `SET_OWNER.bat`, введите ID, затем перезапустите `START_TOURIST.bat`.

## Безопасное обновление с v0.17.0

1. Полностью остановите прежний бот и **сохраните его папку** как резерв.
2. Распакуйте новую версию в **другую** папку.
3. Перенесите `.env` (из старой папки `TOURIST_ONE_CLICK` в новую). Убедитесь, что токен не показывается никому.
4. Если нужно сохранить существующие заявки, скопируйте **только SQLite-базу** по пути `DATABASE_PATH` после её резервного копирования (обычно `data/tourist.sqlite3`). **Не копируйте всю папку `data`**: там также есть актуальная база знаний.
5. Запустите новый BAT. Закройте старое окно Mini App в Telegram и откройте заново, если интерфейс визуально не обновился.

## Структура и диагностика

- `web/tourist-v017.css` — исходный фирменный слой GOLD LOUNGE.
- `web/tourist-v018.css` — типографика, адаптивность, анимации и доступность.
- `web/visual/v017/` — изображения и иконки; PNG/SVG остаются отдельными файлами.
- `web/tourist_logo_original.png` — **исходный неизменённый логотип**.
- `scripts/visual_audit_v018.py` — дополнительный визуальный аудит (требует Playwright/Chromium; используется разработчиком, не нужен для обычного запуска).
- `FULL_QA_WINDOWS.bat` — серверные проверки из Windows (если установлены тестовые зависимости).
