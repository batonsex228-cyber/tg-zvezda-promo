# ТУРИСТ — GOLD LOUNGE · v0.17.0

Новая версия Telegram-бота и интерактивного Mini App в фирменном чёрно-золотом оформлении.

## Что изменено

- Главный экран оформлен изображением барного интерьера; оригинальный логотип использован без изменения файловых байтов. Серый квадрат оригинального изображения скрыт **только круглой CSS-маской при отображении**.
- Новое нижнее меню с шестью отдельными SVG-иконками и активными состояниями. Все вкладки — реальные HTML-кнопки.
- Игровые карточки: караоке, мафия, покер, бильярд; все карточки интерактивны. Караоке направляет обращение администратору, мафия и покер — на соответствующую афишу, бильярд — к выбору времени.
- В афише — отдельные изображения направлений, фильтры и реальные кнопки заявок; свободные места берутся из SQLite, а не из PNG.
- В бронировании бильярда — календарные кнопки на семь дней, восемь кнопок времени, выбор длительности, пересчёт 900 ₽/час для текущей презентационной базы знаний. Фактическую доступность при сохранении брони проверяет сервер.
- Появились иллюстрации пустых списков, стилизованные формы, небольшое интерактивное информационное окно. Сайт не содержит склеенных изображений, имитирующих кликабельные кнопки.
- Старые функции: 150 вопросов и разговорный поиск, Telegram-бот, запись, отмены, админка, уведомления и Google Sheets — сохранены.

## Первый запуск на Windows

1. Распакуйте весь ZIP в папку без сложных символов, например `C:\TOURIST_GOLD`.
2. Откройте папку `TOURIST_ONE_CLICK`.
3. Запустите **`START_TOURIST.bat`**. При первом запуске установщик проверит Python, зависимости и попросит ввести токен BotFather в консоли (в чат его присылать не нужно).
4. Если бот уже создан, откройте его в Telegram и нажмите «Открыть Mini App». Для открытия Mini App внутри Telegram требуется доступный HTTPS-туннель; при его отсутствии бот сможет работать без веб-интерфейса.
5. Для назначения владельца: отправьте `/id`, запустите `SET_OWNER.bat`, введите полученный Telegram ID и перезапустите бот.

## Обновление с v0.16.3

1. Закройте старую консоль бота.
2. Сохраните **копию старой папки**. Распакуйте новый ZIP **в другую папку**.
3. Перенесите файл `.env` из старой папки в `TOURIST_ONE_CLICK` новой версии.
4. При необходимости перенесите только Вашу SQLite-базу по пути, заданному в `DATABASE_PATH` (обычно `data/tourist.sqlite3`), **предварительно сделав резервную копию**. Не заменяйте всю папку `data` — там находятся данные базы знаний проекта.
5. Запустите `START_TOURIST.bat`. В Telegram Mini App при необходимости закройте и откройте приложение, чтобы обновились стили и JS (`?v=0.17.0-gold-lounge`).

## Где лежат визуальные файлы

- `web/tourist-v017.css` — новые стили.
- `web/visual/v017/` — PNG, SVG и реестр ассетов. Отдельные изображения можно использовать повторно.
- `web/tourist_logo_original.png` — исходный логотип (файл не изменять).
- `web/app.js` — действующие обработчики событий, бронирование и диалоговая логика.

Некоторые изображения из набора содержат ранние композиционные референсы с нарисованной эмблемой. **На рабочих экранах используется только оригинальный файл логотипа**, а такие композиции не выводятся вместо него.

## Что было протестировано

- Автоматические регрессионные тесты, локальный FastAPI, SQLite, синтетическая авторизация Telegram.
- Обновлённые реальные CSS и изображения в Chromium, разрешения 320, 360, 390, 430 и 768 px.
- Открытие и закрытие поп-апа, переключение вкладок, афиши, выбор времени и длительности и перерасчёт суммы.

**Не испытывались на реальных аккаунтах:** установка BAT на Вашей Windows, Telegram Bot API с Вашим токеном, живой HTTPS-туннель, Google Sheets и хостинг. При реальном запуске мы проверим их отдельно.
