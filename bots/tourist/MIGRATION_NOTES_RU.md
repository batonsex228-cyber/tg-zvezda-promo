# Обновление «Турист» v0.13.0 → v0.14.0

1. **Остановите** старого бота. Убедитесь, что вторая копия с тем же токеном не работает.
2. Скопируйте старую папку целиком для отката, создайте резервную копию SQLite штатным `BACKUP_WINDOWS.bat` и проверьте её через `RESTORE_CHECK_WINDOWS.bat`.
3. Распакуйте полный `TOURIST_CLUB_STAGE14_V0_14_0_FULL.zip` **в отдельную папку**. Не устанавливайте поверх запущенной программы.
4. Перенесите свой `.env`, актуальную SQLite (и нужные папки с данными/копиями) из предыдущей версии, сохраняя прежний `DATABASE_PATH`. Не переносите БД тестового бота при смене на токен клиента — используйте отдельную БД.
5. Запустите `SETUP_WINDOWS.bat`, `TEST_WINDOWS.bat`, `SMOKE_WINDOWS.bat`. Для реального Telegram дополнительно `FIRST_RUN_CHECK_WINDOWS.bat`.
6. Запустите `START_WINDOWS.bat` или `START_TUNNEL_WINDOWS.bat`. Проверьте гостя, администратора, запрос отмены и повтор с плохой сетью.
7. Новый ручной повтор уведомлений доступен **только владельцу** в Mini App; в штатном режиме используйте автоматические повторы. Ручной запуск нужен лишь после выяснения причины ошибок в админ-диагностике.

**Схема SQLite не меняется.** Клиентские токены, `.env`, архивы резервных копий и JSON ключей не включены в ZIP. Данные не удаляются автоматически при обновлении.
