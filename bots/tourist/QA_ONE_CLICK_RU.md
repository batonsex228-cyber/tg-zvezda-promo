# Отчёт: TOURIST v0.14.0 Windows One Click

Дата проверки: 16.11.2026.

## Что добавлено

- `START_TOURIST.bat` — единый Windows-запуск.
- `scripts/windows_one_click.ps1` — проверка Python 3.11–3.13 x64, при отсутствии загрузка подписанного установщика Python 3.12.10 с python.org, создание `.venv`, установка рабочих зависимостей, скрытый ввод BotFather-токена, безопасная проверка токена и webhook, проверка порта, загрузка Cloudflare Quick Tunnel из официального GitHub, запуск настоящего Telegram-бота и Mini App.
- Резервный режим обычного Telegram-бота при недоступности HTTPS-туннеля.
- `SET_OWNER.bat` — необязательное назначение владельца по ID из `/id`, без редактирования `.env` вручную.
- Повторный запуск повторно использует `.env`, `.venv` и установленный `cloudflared.exe`.
- Новые регрессионные тесты и краткая инструкция `НАЧНИТЕ_ЗДЕСЬ.md`.

## Подтверждено здесь

- 230/230 автоматических Python-тестов, включая 225 оригинальных.
- `scripts.local_smoke`: FastAPI, HTML/CSS/JS Mini App, SQLite, профиль, защита демо.
- `scripts.telegram_flow_smoke`: синтетически подписанная Telegram-сессия, заявки, решения, уведомления без внешней сети.
- `scripts.browser_smoke`: Chromium, тестовый профиль/запись/админка/бильярд, ноль JS ошибок и переполнения.
- `scripts.telegram_mode_browser_smoke`: два тестовых профиля с Telegram HMAC, подтверждение через админку, ноль JS ошибок.
- Контроль структуры BAT и PowerShell-файлов, кодировок UTF-8 BOM для PowerShell и CRLF для BAT.
- Повторный прогон тестов из чистой распакованной пользовательской ZIP-сборки.

## Что пока требует проверки на Windows с реальным токеном

- Фактическая установка Python через `.exe` (если Python отсутствует), установки `aiogram` из PyPI и запуск PowerShell 5.1 на конкретном ноутбуке.
- Загрузка/запуск `cloudflared.exe` из GitHub и работа Quick Tunnel в Вашей сети/VPN.
- Настоящие `/start`, `/id`, команды, сообщение гостю, меню Mini App внутри Telegram на телефоне.
- Доступ к настоящей Google-таблице и выделенному серверу (не нужны для этой локальной проверки).

**Важно:** эти проверки не подтверждают, что BAT уже успешно выполнился на Windows. При невозможности загрузить внешний компонент запускается резервный режим; Mini App будет доступна только локально, пока HTTPS не работает. Токен в архив не включён.
