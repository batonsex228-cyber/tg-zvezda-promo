- Telegram и новый раздел «Вопросы» в Mini App используют единый `app/assistant.py` и личный контекст темы на 25 минут в SQLite.

- Реальное число мест на играх берётся из SQLite, а не из текстовых заготовок. Механизмы записей и подтверждения администратора из прошлой версии сохранены.
- Сложные вопросы без надёжного ответа не выдумываются: в Telegram создаётся обращение сотруднику; в Mini App предлагается перейти в «Связь» (с согласия человека).

## Один клик на Windows 10/11

1. Закройте старое окно `START_TOURIST.bat`, чтобы Telegram-бот не был запущен в двух копиях.
2. **Сохраните старую папку** как резервную копию. Не удаляйте из неё `.env` и `data/tourist.sqlite3`.
3. Распакуйте этот ZIP **полностью** в новую папку, например `C:\TOURIST_V016`. Не запускайте BAT из окна предпросмотра архива.
4. Если ранее уже использовали бота, перенесите из старой папки `TOURIST_ONE_CLICK\.env` в такую же папку нового проекта. Если хотите сохранить пользователей и заявки, **скопируйте из старой папки только SQLite-файлы вашей базы** (обычно `data\tourist.sqlite3` плюс `-wal`/`-shm`, если они есть). Делайте это **после остановки старого бота**. Не заменяйте всю новую папку `data`, в ней появилась база знаний.
5. Запустите **`START_TOURIST.bat`**. При первом запуске будут автоматически подготовлены Python и зависимости, затем программа попросит токен, если его нет в `.env`.
6. В Telegram: `/start`, затем вопросы обычными словами: «Добрый вечер, подскажите адрес», «Когда следующая мафия?», «А сколько стоит?», «Где я могу забронировать бильярд?». Откройте Mini App и новую вкладку **«Вопросы»**.
7. Права владельца: отправьте `/id`, запустите `SET_OWNER.bat`, введите ID и перезапустите основной BAT. Токен никому не пересылайте.

## Технические детали

- Сайт и API запускаются вместе с Telegram long polling на `127.0.0.1:8000`.
- Для запуска Mini App внутри Telegram нужен публичный HTTPS; Windows ONE CLICK пытается запустить временный Cloudflare Tunnel. При недоступности туннеля текстовый бот и локальный сайт могут продолжить работу, Mini App будет недоступна извне.
- Локальный просмотр сайта: `http://127.0.0.1:8000` (с демо-доступом — только при запуске отдельного `START_DEMO_WINDOWS.bat` без токена).
- Если добавляется новый клиентский токен, используйте отдельную базу `DATABASE_PATH`: чужие пользователи и права сотрудников не должны переноситься без согласования.
- `AI_MODE=off` по умолчанию. Основной диалог работает локальными правилами, вопросами и памятью контекста — это **не гарантирует понимания любого предложения**. Опциональный Ollama из предыдущих версий сохранён, но не обязателен.
- Демо-данные следует **заменить на утверждённые факты** прежде чем представлять бот как официальный сервис реального заведения. Разрешение на использование бренда в портфолио нужно согласовать с владельцем.

## Как проверить

При наличии установленных зависимостей:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m scripts.local_smoke
```

Для диагностики Windows используйте встроенные `CHECK_WINDOWS.bat` и `FIRST_RUN_CHECK_WINDOWS.bat`. Для QA двух отдельных Telegram-пользователей можно запустить `python -m scripts.showcase_browser_smoke`, если установлен Chromium и Playwright.

## Не проверено здесь

Установка и запуск BAT на **вашем конкретном ноутбуке**, реальная доставка сообщений Telegram, Cloudflare в вашей сети и Google Sheets с реальным аккаунтом. Поэтому сначала проверьте новую версию со своим тестовым токеном и сообщите, если конкретный шаг установки завершится ошибкой.
