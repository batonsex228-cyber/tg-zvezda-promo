# «Турист» v0.16.3 — обновление клиентских текстов

Обычный запуск на Windows остался прежним — `START_TOURIST.bat`.

## Если бот уже запущен на ноутбуке

1. Остановите прежний BAT (`Ctrl+C`), старую папку оставьте резервной копией.
2. Распакуйте новую полную сборку в отдельную папку.
3. Перенесите **только `.env`** и рабочую SQLite-базу из прежней папки (обычно `data/tourist.sqlite3`), если хотите сохранить существующие записи. **Не копируйте всю папку `data`: в новой лежит обновлённая база из 150 ответов.**
4. Запустите `START_TOURIST.bat`. После нового `/start` откройте Mini App. Если Telegram показывает старое оформление, полностью закройте Mini App и откройте снова.
5. Проверочные вопросы: «Сколько стоит мафия?», «Время работы?», «По чём два часа бильярда?», «Есть меню?», «Когда следующая игра?».

## Что исправлено

Клиентский текст больше не содержит упоминаний внутреннего режима показа: в 150 FAQ, приветствии Telegram, расчёте стоимости, названиях мероприятий и экранах Mini App. Внутренние поля базы по-прежнему отличают искусственно сформированные события от обычных — для безопасной смены владельца и передачи проекта.

**Важно владельцу:** цены, график, меню и акции в этой сборке вымышлены, подготовлены для презентации. Прежде чем использовать её для настоящих клиентов бара, согласуйте эти данные с заведением. Этот комментарий находится только в инструкции владельца — гости его не видят.

Оригинальный PNG-логотип не изменялся. Публичные кнопки и дизайн сохранены.
