# TOURIST SHOWCASE v0.15.0 · локальная проверка

## Проверялось без реального токена

- Регрессионные тесты исходного проекта + новые тесты автосоздания и изоляции деморасписания, обращения/ответа, API-прав доступа, защиты от дублей, свободных вопросов и отключённого/локального AI.
- FastAPI, SQLite, настоящие HTTP-запросы из тестового клиента, подписанные тестовые данные Telegram.
- Chromium 390×844: профиль, игры, бильярд, админка, роль, журналы, а также новый сценарий **гость → обращение → сотрудник → ответ гостю**.
- Проверка JS-ошибок и горизонтального переполнения.
- Чистая распаковка релизного ZIP и повторный прогон.

## Что локальные проверки НЕ доказывают

- Реальную работу ChatGPT/LLM без подключённой модели (правила отвечают на ограниченный круг вопросов, неизвестные вопросы уходят человеку).
- Доставку сообщений Telegram без настоящих пользовательских аккаунтов и BotFather-токена.
- Установку зависимостей на Windows, HTTPS Cloudflare и оплату/доступность хостинга.

## Эксплуатационные риски

- Cloudflare Quick Tunnel — временный адрес для тестов. Он может измениться при перезапуске.
- При передаче клиенту нужны отдельные `.env`, SQLite, токен и администратор, плюс согласование расписания и цены.
- Смену токена поверх существующей базы выполняйте только осознанно: защита базы блокирует чужие токены.
