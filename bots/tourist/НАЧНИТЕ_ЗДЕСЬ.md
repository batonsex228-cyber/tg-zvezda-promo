# «Турист» — запуск на Windows в один клик

## Самый простой вариант

1. Полностью распакуйте ZIP, например в `C:\TOURIST`. **Не запускайте BAT внутри окна ZIP или предпросмотра архива.**
2. Дважды щёлкните **`START_TOURIST.bat`**.
3. На первом запуске разрешите скачивание необходимых компонентов, если Windows/антивирус спрашивает об этом. При появлении `BOT_TOKEN` **вставьте токен, полученный у `@BotFather`, и нажмите Enter**. Токен при вводе не отображается.
4. Установщик сам проверит совместимый Python, при необходимости установит Python 3.12 x64 для текущего пользователя, создаст `.venv`, установит библиотеки, проверит Telegram и попробует скачать Cloudflare Tunnel и запустить Mini App.
5. Откройте Вашего бота в Telegram и отправьте **`/start`**. Затем нажмите **«Открыть Mini App»**, если HTTPS-туннель запустился.

**Готово.** Окно BAT оставляйте открытым: пока ПК работает и не спит, бот отвечает. При закрытии окна программа останавливается. При следующем запуске токен заново не спрашивается, Python и библиотеки не скачиваются повторно, если не изменился список зависимостей.

## Где и как это работает

- Локальный сайт и API: `http://127.0.0.1:8000` на Вашем ноутбуке. Это техническая ссылка: **для работы личного кабинета внутри Telegram используйте кнопку Mini App**, а не открывайте `localhost` на телефоне.
- Mini App: через **бесплатную временную HTTPS-ссылку Cloudflare Quick Tunnel**. Для этого должны открываться Telegram API и GitHub/Cloudflare; VPN/антивирус могут влиять. Ссылка может меняться **при каждом запуске**. Поэтому после перезапуска открывайте Mini App через новую кнопку из сообщения `/start`.
- Если Quick Tunnel недоступен, BAT автоматически попробует запустить **обычный Telegram-бот**. В этом случае команды бота работают, но открыть Mini App из Telegram не получится, пока туннель не заработает.
- Обязательно нужен интернет при первом запуске. Python и библиотеки ставятся в Вашем профиле/папке проекта, глобальные системные настройки не меняются.
- Токен хранится только в локальном **`.env`**, не присылайте его в чат и не выкладывайте эту папку в открытый доступ.

## Как включить админ-панель владельца

При запуске одного токена достаточно для работы **самого бота, регистрации и Mini App**. Чтобы включить **владельца/админ-панель**, выполните один раз:

1. Напишите боту `/id` — он ответит Вашим числовым Telegram ID.
2. Дважды щёлкните **`SET_OWNER.bat`** и введите это число. Скрипт сам сохранит его в `.env`.
3. Остановите работающего бота (`Ctrl+C` в окне) и ещё раз нажмите `START_TOURIST.bat`.

Это отдельный осознанный шаг безопасности: **Telegram Bot API не сообщает ID владельца по токену**, а автоматически назначать первым вошедшего владельцем было бы опасно. Другие настройки для первого запуска не нужны.

## Что делать при ошибке

| Что написано | Что сделать |
| --- | --- |
| Не удалось скачать Python или библиотеки | Проверьте интернет/VPN, место на диске; повторно запустите BAT. Можно вручную установить 64-битный Python 3.12 с python.org |
| Не удалось проверить Telegram | Проверьте токен у `@BotFather` и доступность `api.telegram.org`. Если ошиблись токеном, в появившемся вопросе напишите `TOKEN` |
| Активен webhook | У бота уже есть другая запущенная реализация. Остановите прежнего бота и отключите webhook **сознательно**, прежде чем запускать polling. Программа ничего не удаляет сама |
| Порт 8000 занят | Закройте другую копию бота или программу, занимающую порт 8000 |
| Cloudflare не запускается | Команды Telegram должны продолжить работу без Mini App; проверьте доступность GitHub и Cloudflare, VPN и брандмауэр |
| Нет прав администратора | Отправьте `/id`, установите `OWNER_TELEGRAM_ID` и перезапустите BAT |
| Открыли Mini App со старой кнопки | Отправьте боту новое `/start` и откройте свежую кнопку |

## Что ещё важно

Это **локальная тестовая сборка**, а не сервер для гостей 24/7: ноутбук должен быть включённым, не уходить в сон и иметь интернет. Не пересылайте временную ссылку посторонним, не храните в тестовой базе реальные персональные данные клиентов без согласования и не используйте Quick Tunnel для коммерческого размещения.

Обновляя проект, **сначала** сделайте копии `.env` и `data\tourist.sqlite3`; не копируйте базу другого бота без проверки привязки к токену. В ZIP нет токенов, установленных библиотек или клиентских данных.

## Что проверено при сборке

Пройдены исходные тесты проекта, проверка локального FastAPI и содержимого ZIP. **На настоящем Windows-ноутбуке, с Вашим токеном и реальным Telegram Mini App автоматический установщик ещё не проверен.** При проблеме пришлите текст/скрин окна **без токена**.
