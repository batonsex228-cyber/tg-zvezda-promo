# ТУРИСТ 0.18.3 — CLEAN UI / Windows ONE CLICK

Версия: `0.18.3-clean-ui`. Полный Telegram-бот и Mini App с 150 FAQ, записью на игры и бронированием бильярда. Изменения в этом выпуске визуальные и упаковочные, бизнес-логика и данные не заменяются.

## Что изменено
- Убраны строка «Караоке • Мафия • Покер • Бильярд», счётчик `01 / 03`, ненужные подзаголовки и стрелки на кнопках.
- Верхняя шапка содержит один оригинальный логотип и название. Личный кабинет доступен из нижнего меню.
- Второй логотип на главной фотографии удалён из HTML. Исходная фотография логотипа не содержала и не изменялась.
- Главный баннер стал компактнее. Stengazeta используется в акцентных заголовках, основной текст остался читабельным.
- Изображения оптимизированы; никакие картинки не загружаются со сторонних сайтов.

## Первый запуск
1. Распакуйте ZIP полностью в отдельную папку, например `C:\TOURIST_0183`.
2. Откройте подпапку `TOURIST_ONE_CLICK` и запустите `START_TOURIST.bat`.
3. При первом запуске введите токен тестового Telegram-бота от @BotFather в окне установщика. Никому его не отправляйте.
4. Для Mini App внутри Telegram нужен HTTPS-туннель или публичный HTTPS-домен. Окно BAT держите открытым.
5. Для прав владельца отправьте боту `/id`, запустите `SET_OWNER.bat`, введите ID и перезапустите главный BAT.

## Обновление работающего бота
1. Остановите прежнюю версию и сохраните её папку целиком как резерв.
2. Распакуйте новую версию отдельно, не поверх предыдущей.
3. Скопируйте прежний `.env`, чтобы сохранить токен и настройки.
4. Если нужна история заявок, заранее сделайте резервную копию и перенесите только SQLite-файл из `DATABASE_PATH` (обычно `data/tourist.sqlite3`). Не копируйте всю папку `data`: там лежит база знаний.
5. Запустите `START_TOURIST.bat`, полностью закройте старое окно Mini App и откройте снова. У CSS/JS новый параметр версии для обхода кэша Telegram.

## Пределы локальной проверки
Пройдены тесты, Chromium, синтетическая Telegram-авторизация и API на временной SQLite. Настоящие Bot API, HTTPS-туннель и Windows BAT проверяются уже на Вашем ноутбуке. Оригинальный `web/tourist_logo_original.png` не менялся.
