ZVEZDOCHKA TELEGRAM v1.0.2 - WINDOWS PYTHON BOOTSTRAP

Ошибка, которую исправляем:
[ERROR] Python 3.11-3.13 still cannot be located

Решение: один START_TELEGRAM.bat больше не полагается на Python в PATH. Он скачивает uv (проверка SHA-256), создаёт изолированный Python 3.12, устанавливает библиотеки и запускает бота.

УСТАНОВКА ПАТЧА
1. Закройте старое окно бота.
2. Распакуйте PATCH в ту же папку бота с заменой файлов.
3. Не удаляйте .env, runtime, .venv.
4. Запустите START_TELEGRAM.bat.

Для первого запуска нужен Интернет и Windows 10/11 x64.
Если GitHub не открывается, скопируйте ошибку без токена.
